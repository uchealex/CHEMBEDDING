Cross-Domain Transfer Learning from Peptides to Lipids Using a Multi-Property Fine-Tuned LLM

Description of model files:

Multi-task learning of retention time performs better than a single-task head for lipids. (Filename: chemberta_lipid_rt_RTrdkit.ipynb)

Multi-task learning of retention time performs better than a single-task head for peptides. (Filename: chemberta_peptide_rt_RTrdkit_250k.ipynb)

Transfer learning from peptide to lipid:
Part A: chemberta_TransferLearning_peptide_RTrdkit_Lipidmetlin_250k_A.ipynb
Part B: chemberta_Transferlearning_peptide_RTrdkit_Lipidmetlin_250k_B.ipynb

All files can be run using Google Colab.
